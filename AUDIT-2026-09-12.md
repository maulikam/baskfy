## 3. Engine / data correctness

- **#5 and #6 above are P0.** Run the `source='kite'` count first; if non-zero, tag deep-history rows `kite_adjusted` (or filter on `date < seam`) and `reprocess_instrument` every affected instrument.
- **M29 splice is a one-time anchor** — `deep_backfill.py` scales the Kite segment once; `reprocess_instrument` rescales only `source != 'kite'`, so every later split reopens a `1/f` step at 2024-01-01 (`high_ath` at `factors.py:396` reads across it).
- **Combined corporate-action purposes lose a leg** — `nse.py:994-1001` takes the first keyword: "SPLIT … AND BONUS 1:1" applies the split and drops the bonus (factor wrong 2×); `_parse_dividend` (`:989`) keeps only the first `RS x`. Audit `corporate_action.raw` for rows containing both `SPLIT` and `BONUS`.
- **Idempotency race in the gateway** — `gateway.py:244` checks `_sent`, awaits `order_slot()`, writes `_sent` only after the broker returns (`:295`); no lock, and `_sent` is never rebuilt from `orders_journal.jsonl`. Reserve under a lock before the await; replay the journal on construction.
- **`assert_tradeable` raises mid-batch** (`gateway.py:174`) while the overnight-option guard two lines later returns BLOCKED so one refused leg cannot abort a batch that already placed real orders. An SGB leg in a plan produces the half-executed rebalance the rate-limiter comment describes.
- **NaN passes every stop/price check** — `gtt.py:261-268` uses `<=`/`>=`; `gateway.py:219,239` likewise. `basket.py:259` can produce a NaN trigger from `volatility_one_year`. `math.isfinite` in `refuse_stop` and `place`.
- **Risk layer disarmed by defaults** — `gateway.py:143` `gross_exposure: float = 0.0`; `risk.py:52` checks per-order not per-position; `risk.py:26-33` kill switch and daily count are in-memory and roll on host-local `strftime`, so a restart clears a tripped daily-loss cap.
- **NaN sails through the desk filters** — `score.py:107-116` pandas `<` with NaN is False, so a NULL `median_volume_one_year` / `ma_200` / `away_from_high_one_year` is *not* rejected (non-negotiable 7 wants NULL = rejected).
- Dead half-size rule (`basket.py:235-237` `listed_hist_ok = True`); `windows.py` docstring + `bars_required` describe the pre-parity N+1 convention while `factors.py:298-313` uses N — exactly the doc-vs-code trap CLAUDE.md warns about; RSI gap handling double-counts a missing bar (`factors.py:472-483`); `stop_from_vol` band journals `too_close` for every swing/VBT/TWT stop (noise).
- Law 1 leaks in `packages/core`: `reference_export.py:196-210` (disk), `models/integrations.py:119`, `models/admin.py:108` (clock), `trading_calendar.py:68` (package resource). Minor.
- Worker: `reject_on_worker_lost` + OOM = unbounded redelivery with no retry counter; catch-up re-proposes a `derived` holiday every sweep until `reconcile_calendar` runs; NSE `_throttle` is a silent no-op when no limiter is wired and cookies are never re-primed on 401/403 (`nse.py:703-711`) — plausible cause of the §17 ~600-request stall; `KiteConnect(api_key=…)` relies on the SDK's 7 s default timeout.
- Three "today" clocks in the API — server-local `date.today()` (`vbt.py:548`, `routers/kite.py:194`, `routers/portfolios.py:562,689,794`), UTC (`portfolio_overview.py:2507…`, `routers/swing.py:979,1013`, `curated_sip.py:142`), IST (`brokers.py`, `invoices.py`). Between 00:00 and 05:30 IST the first two stamp yesterday. `invoices.today_ist()` already exists.
- Curated investments are valued at **cost** (`curated_investments.py:290`, `curated_costs.py:75` pass `avg_price` as the mark), so returns read 0 and after-fee return reads −fees, with no `marked_at_cost` flag.
