## Contract — decided BEFORE fan-out

### The shape we are building toward

```
portfolio(id, user_id, parent_id?, broker_account_id?, name, created_at)
  └─ nests: parent_id → portfolio.id, same user, no cycles, depth ≤ 6
  └─ broker_account_id NULL = spans brokers (a roll-up node); NOT NULL = attributable
portfolio_holding(portfolio_id, instrument_id, broker_account_id, qty, avg_price, added_on)
  └─ PK becomes (portfolio_id, instrument_id, broker_account_id)
portfolio_sleeve(..., kind IN ('screen','manual','basket'), screen_id?, basket_id?)
cb_investment(..., portfolio_id?)   ← nullable FK; an investment may sit outside any portfolio
```

### Hard rules inherited (precedence order from root CLAUDE.md)

1. **Safety rails.** `DRY_RUN=true`. No live order. `kite-momentum-rebalancer/data/portfolio.db`
   untouched — this tree is Postgres-only. `frozen/strangle/` untouched.
2. **Law 1:** `packages/core` touches nothing — no DB, no network, no clock. The graph and unit
   math are pure functions over plain data.
3. **Law 2:** no leaf goes near `packages/execution` or any order path. No `POST /execute`.
4. **House rule 3:** no `# type: ignore`, no `any`, no swallowed exceptions.
5. **House rule 9:** money and quantities are `numeric`, never `float`.
6. **Non-negotiable #2:** any holdings quantity = `quantity + t1_quantity + collateral_quantity`.
7. Track B flags stay false. No web execute route. Nothing here needs C3.

### Out of scope (hard)
- Writing broker adapters for the nine unwired brokers. C2 makes the catalog *honest*, it does
  not make the brokers *work*. New adapters need credentials → `NEEDS-MAULIK.md`.
- Consolidated net worth that pretends unwired brokers returned data.
- Flipping any Track B flag. Paid launch. RLS (P4.10). Two-token OAuth (P4.2).

### Provenance enum (C1 — the money-safety contract)
`holdings_for_broker` returns `HoldingsResult(rows, source)` where
`source ∈ {"live", "fixture", "empty", "unwired"}`. The router reports `source` verbatim.
A live Kite fetch that returns rows MUST report `"live"`. This is the defect being fixed;
no leaf may collapse the enum back to a boolean.
