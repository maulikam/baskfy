# DECISIONS-PM — judgement calls, numbered by module

Pre-taken with the pack (9 Nov 2026, ⚠ UNREVIEWED):

- **PACK.1** Label = *touches 2× within 250 sessions* (`touch`), not `held`, not graded relevance, not
  24 months, not a triple barrier (STRATEGY §2–3). Reverse: rebuild with another `--mb`/`--target`.
- **PACK.2** Model = LightGBM lambdarank, one query per session, 31 leaves, 300 fixed rounds; early
  stopping on a time tail was too noisy. Reverse: `ModelConfig`.
- **PACK.3** Book = monthly tranches, top-20, 250-session hold, 25 bps a side, investable floor
  ≥ ₹50 and ≥ ₹5 cr/day. The index gate is **off** (cost 11 CAGR points for 3 of drawdown).
- **PACK.4** The sleeve is read-only, no flag exists. Buying a tranche is a human's `/analyze`.
- **PACK.5** The pack lives under a new top-level `machinelearning/` (Maulik, 9 Nov 2026), not
  `legacy/python/research/`, because it is not legacy and will graduate into `baskfy_core.mb`.
- **PM0.1 (pending)** `lightgbm` enters the stack — outside `docs/02-tech-stack-adr.md`. Research-only
  until PM6; record in `docs/DECISIONS-MERGE.md` when it reaches `packages/core`.
- **PM3.1** ⚠ UNREVIEWED Sector treated as static (today's classification applied to history): a small, known leak until a dated source exists. Flagged in the `instrument_sector` table comment, `portfolioml/sector.py` (`STATIC_SECTOR_FEATURES`) and `run_pm4.py`'s output.
- **PM6.1 (pending)** Scoring stays a Python worker task; Rust port of a LightGBM tree walker deferred.
- **PM0.2** ⚠ UNREVIEWED Export reads index closes from `index_bar_daily` (2011→, keyed by `index_master.id`, not `index_def.id`), not `index_snapshot_daily` (2017→): bars now start 2011, so snapshots would null market features for 2011–17. Closes match the old file to 0.05 %. Mom50 stays on snapshots (unused beyond a dropped column). Container default `baskfy-local-postgres-1`, override `BASKFY_PG_CONTAINER`.
- **PM0.3** Env: `uv venv --python 3.12` (system default 3.15); LightGBM needs `brew install libomp`.
- **PM1.1** ⚠ UNREVIEWED Two NSE feeds: `corporates-financial-results` (Reg 33, XBRL 2018 → Dec 2024) and `integrated-filing-results` (Mar 2025 →). The plan named one; the first stops at Dec 2024. `--since` defaults to 2018-01-01 (no XBRL before), not the plan's 2017.
- **PM1.2** ⚠ UNREVIEWED Features join on `available_on` (stamp ≥ 15:30 IST → next day), stricter than the plan's `filed_on ≤ date`: most results land after the close. Revisions stamp at `revised_Date`. PK adds `period_type`, or a same-day standalone + consolidated pair collides.
- **PM1.3** ⚠ UNREVIEWED Ingest is Rust (`crates/providers/src/nse_results.rs`, worker `fundamentals_pit`); features stay in `portfolioml/fundamentals.py`, since `baskfy_core` Python is legacy since RF3. EPS growth dropped: filed EPS is not restated for bonuses (Reliance halves in Oct 2024); PAT growth used. Code map rewritten 9 Nov: `baskfy-core` stays pure, the worker does I/O, `06` and BASKFY-INTEGRATION updated.
- **PM1.4** Limits: balance sheets are half-yearly and start about Sep 2022, cash flow about Sep 2021 (3-name sample, both feeds), so D/E, ROCE, CFO/PAT are sparse in training. Banks have no EBITDA. Per period the consolidated filing is fetched, else standalone, to bound requests.
- **PM4.0** Maulik, 9 Nov 2026: PM4 AC1 covers signal-years 2024 **and** 2025, same two tests each, because 2024 already passed on price-only. Hit-rate base stated as the investable universe's.
- **PM1.5** ⚠ UNREVIEWED In training PM1 mostly tests growth and margins: balance sheets start about Sep 2022 and cash flow about Sep 2021, against the kickoff's "only from 2025" (that figure was PM1.4's earlier error). They are absent from the 2024 fold's training and thin in 2025's. If PM4 fails, record "growth/margins did not fix 2025", not "fundamentals do not work". Older balance sheets = MCA annual-report XBRL, later module **PM5b**.
- **PM4.1** ⚠ UNREVIEWED 2024 investable top-20 moved +1.0 → +5.1 % between exports with the same 240 picks' worth of signal dates and investable universe rows 10,693 → 10,691, so Q4-2024 paths were already complete on 10 Sep (kickoff said otherwise). What changed: bars from 2011, so the 2024 fold's training went 145,460 → 244,129 rows, and the SEAM-1 price repair. Not separated. Single-year gates are fragile: PM4 is judged per year (2024, 2025) **and** pooled 2024+2025.
- **PM2.1** ⚠ UNREVIEWED NSE's shareholding archive starts at Sep 2021 (a 2017–21 window returns nothing older; 4-name sample), first stamps Jan 2022 (a batch load, later than the true filing, so safe). The kickoff's "> 85 % from 2019" cannot be met: AC read as > 85 % from 2022. So shareholding is absent from the training of early folds and partial for 2024/2025. Older history needs another source (BSE, later module).
- **PM2.2** ⚠ UNREVIEWED `promoter_pledged_pct` = encumbered share of the promoters' own holding, every kind (the newer schema separates pledge, NDU, other; the older does not), so it stays comparable. Scale read from each filing's own 100 % row (filings report 25.83 or 0.2583). Promoter and public from the listing; the rest from XBRL. PK as specified; `filed_at`, `is_revision`, `source_url` added for PM1's shape. Listed XBRL that NSE 404s is skipped and counted, not a symbol failure.
- **PM3.2** ⚠ UNREVIEWED `max_per_sector` defaults to 3 and applies only when the frame has a `sector` column, so every price-only run reproduces. A name with no sector is not one sector. If the cap would leave a tranche short, the next best names fill it.
- **PM3.3** ⚠ UNREVIEWED `mcap_cr` uses shares from the last filing, so it reads low between a bonus or split ex-date and the next filing (Reliance: about a quarter at half). Accepted for a decile and log feature; the median error against `fundamental_daily` prints in `run_pm4.py`. `instrument_sector` refreshes in the nightly fundamentals step, so names that no longer trade get no sector.
- **PM4.2** ⚠ UNREVIEWED `run_pm4.py`'s gate compares uncapped books, identical to STRATEGY §3/§4, so it measures information alone; the cap-3 book prints beside them. Coverage guard reads the TTM figure from 2019. Price-only through it reproduces §3's six AUCs exactly (0.690, 0.692, 0.682, 0.653, 0.658, 0.601).
