# QUESTIONS — for Maulik, with the pack's standing default for each

The run never waits on these. Each carries the default it proceeds on; an answer here (or in
`NEEDS-MAULIK.md` § VBT) becomes a `DECISIONS-VB.md` entry and the module that reads it adjusts.

| # | Question | Standing default the run uses |
|---|---|---|
| Q1 | **The money.** What capital does this sleeve get, and is equal weight across ten slots the sizing you want? Written into `DECISIONS-VB.md` as the risk decision `02` §3.4 requires | `vb_config.sleeve_capital_inr` seeded at **0**; nothing is planned until you set it. The rules are drilled at the study's own frame: **₹10 lakh, equal weight, 10 slots** (STRATEGY §3–4), which is what every fixture and the backtest use |
