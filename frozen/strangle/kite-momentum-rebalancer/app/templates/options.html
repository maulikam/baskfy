Kite lists only live contracts: checked on 16 Aug 2026, zero of the eighteen NIFTY expiries on file were in the past. Once a contract expires its token cannot be looked up again, and historical_data takes a token rather than a symbol — so an option's price history becomes unreachable the moment it expires unless the token was written down first. Each arm stores its own, which is the difference between a dataset and a summary.

It also settles an open question. Whether a token recorded before expiry still resolves after it could not be tested, because no such token existed. The first arms to pass their expiry will say.
